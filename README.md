# Library Loan Data Warehouse
The project covers the main stages of a data warehousing workflow, from data generation and ETL to multidimensional modeling, OLAP analysis, and visualization.

## Overview
A data warehouse and OLAP project focused on the analysis and monitoring of library book loans over the 2023–2025 period.

The objective is to analyze library loan data over the 2023–2025 period in order to identify borrowing trends, the most frequently borrowed books, loan durations, late returns, lost books, and the financial impact of subscriptions and penalties.

## Technologies

- **Talend** — ETL and data generation
- **PostgreSQL** — Data warehouse
- **Schema Workbench** — OLAP cube
- **Power BI** — Data visualization
- **Python** — Data preparation

## Data

The book data is based on the Goodreads Books dataset, while additional data such as readers and loans was generated using Talend.

## ETL Pipeline

The ETL process consists of:

1. **Extract** : Importing the book dataset and generating additional data.
2. **Transform** : Cleaning and enriching the data, including adding book categories.
3. **Load** : Loading the transformed data into PostgreSQL.

## OLAP Analysis

An OLAP cube was created using Schema Workbench to perform multidimensional analysis.

Examples of analyses include:

- Most borrowed books by year
- Books with the longest loan durations
- Revenue generated by subscribed users
- Analysis of loan activity and trends

## Visualization

The results were visualized using Power BI, providing a clearer overview of borrowing activity and helping support data-driven decision-making.
